# Venyl для личного iPhone

Это отдельный iOS-проект, а не готовый IPA. Он открывает https://venyl-music.onrender.com/ внутри приложения без панели браузера. Пользователи, музыка и авторизация остаются на существующем сервере. Исправления сайта из предыдущего архива появятся в приложении только после их публикации на Render.

Включены: постоянное хранилище сессии WKWebView, отступы под экран iPhone, системная иконка Venyl, индикатор загрузки, повтор после ошибки подключения, переходы назад жестом, открытие внешних ссылок в системных приложениях и диалоги подтверждения сайта.

## Сборка

Workflow `.github/workflows/build-iphone.yml` собирает этот проект на macOS при pull request с изменениями iOS. В результатах запуска Actions скачай артефакт Venyl-iPhone-unsigned и распакуй Venyl-unsigned.ipa. Это неподписанная сборка для последующей установки через AltStore Classic на Windows.

После добавления workflow в основную ветку его также можно запустить вручную: Actions → Build Venyl iPhone → Run workflow.

Бесплатную подпись требуется обновлять раз в 7 дней. Пароль Apple Account не нужен в GitHub или в чате. Приложение загружает текущий сайт на Render, поэтому изменения веб-сайта появляются после отдельного деплоя сайта.

Первая версия требует интернет. Фоновое воспроизведение, нативный аудиоплеер и офлайн-загрузка не реализованы. Установка и поведение на реальном iPhone требуют отдельной проверки.

## На Mac

В папке ios выполни `xcodegen generate`, открой Venyl.xcodeproj, выбери свою команду в Signing & Capabilities и запусти на iPhone.
